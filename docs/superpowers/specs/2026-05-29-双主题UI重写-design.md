# 双主题 UI 重写设计文档

> 日期: 2026-05-29 | 状态: 已确认

## 概述

对"粑粑升职记"进行 UI 视觉重设计，实现「金融交易所」和「实验室报告」双主题切换系统，全页面 GSAP 动画覆盖。

## 技术栈

- **框架**: uni-app 3 (Vue 3 + TypeScript + Pinia) + Vite 6
- **样式**: SCSS + CSS 自定义属性（主题变量）
- **动画**: GSAP 3 (Core + ScrollTrigger)
- **字体**: JetBrains Mono（交易所等宽）+ IBM Plex Serif（实验室衬线）

## 一、主题系统架构

### 切换机制

- CSS 自定义属性（CSS Variables）驱动全局主题
- Pinia store (`useThemeStore`) 管理主题状态，持久化到 `uni.setStorageSync`
- 切换时 GSAP 平滑过渡（全局 0.4s）
- 两个主题：`stock`（金融交易所）和 `lab`（实验室报告）

### 术语映射

`src/config/theme-labels.ts` 集中管理，按 `{ key: { stock: '...', lab: '...' } }` 格式：

| 数据项 | 交易所 | 实验室 |
|--------|--------|--------|
| 拉屎时长 | 持仓时间 | 实验时长 |
| 收益金额 | 浮动盈亏 | 经济产出 |
| 秒薪 | 实时报价 | 代谢率 |
| 今日次数 | 当日成交 | 样本计数 |
| 历史记录 | 交易流水 | 实验日志 |

### 主题切换动画

```typescript
// 主题切换时平滑过渡CSS变量
gsap.to(document.documentElement, { duration: 0.4, ease: 'power2.inOut',
  onUpdate: () => setCSSVariables(newTheme)
});
```

## 二、组件体系

提取 7 个公共组件：

| # | 组件 | 路径 | 职责 |
|---|------|------|------|
| 1 | `NumberTicker` | `src/components/NumberTicker.vue` | 数字滚动（收益/时长/秒薪） |
| 2 | `ThemeCard` | `src/components/ThemeCard.vue` | 统一卡片容器，主题感知 |
| 3 | `PageTransition` | `src/components/PageTransition.vue` | 页面切换容器 |
| 4 | `ProgressRing` | `src/components/ProgressRing.vue` | 环形进度（计时器/经验） |
| 5 | `DataChart` | `src/components/DataChart.vue` | Canvas 图表封装 |
| 6 | `BadgeIcon` | `src/components/BadgeIcon.vue` | 成就徽章 |
| 7 | `ToastPopup` | `src/components/ToastPopup.vue` | 弹窗/通知 |

### GSAP 分层策略

- **L1 微动效** (≤0.3s): 按钮/图标/tab 切换
- **L2 入场动画** (0.4-0.6s): 卡片/列表项/图表 stagger
- **L3 沉浸动效** (持续): 计时器环/数字滚动
- **无障碍**: `gsap.matchMedia()` 匹配 `prefers-reduced-motion`

### Vue 3 集成模式

```typescript
// 每个组件统一模式
<script setup>
import { onMounted, onUnmounted, ref } from 'vue';
import { gsap } from 'gsap';

const container = ref(null);
let ctx: gsap.Context;

onMounted(() => {
  if (!container.value) return;
  ctx = gsap.context(() => {
    // 动画代码
  }, container.value);
});

onUnmounted(() => ctx?.revert());
</script>
```

`gsap` + `ScrollTrigger` 在 `main.ts` 全局注册一次。

## 五、实施顺序

分 4 个阶段：
1. **基础建设** — 主题系统 + 术语配置 + GSAP 注册 + 7 个组件
2. **Tab 页重构** — 首页、历史、统计、个人中心（4 个 Tab 页）
3. **子页面重构** — 计时器、结算、登录、薪资、职级、成就、战队、周报、运势（9 页）
4. **收尾** — 主题切换入口 UI、全局动效调优、`prefers-reduced-motion` 支持
