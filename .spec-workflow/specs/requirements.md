# Requirements Document

## Introduction
「粑粑升职记」是一款让用户在带薪拉屎的过程中获得乐趣、计算收益并与团队互动的应用。本需求文档描述了应用的注册、计时、结算、统计、徽章成就、战队社交和周报在前端的实现要求，确保用户能拥有流畅、美观且富有趣味的体验。

## Alignment with Product Vision
本功能集完全对应于 `product.md` 中关于“带薪如厕计时”、“结算与评价”、“职级晋升”、“成就勋章”、“拉屎战队排行榜”及“周报”的规划。通过极简化、游戏化的交互界面，落实“带薪摸鱼”文化。

## Requirements

### Requirement 1: 用户注册初始化与重定向
- **User Story**: 作为一个首次使用的用户，我希望能够快速输入我的昵称和薪资参数，以便应用开始计算我的摸鱼收益。
- **Acceptance Criteria**:
  1. 系统检测到用户未注册（本地 LocalStorage 及 Store 中不存在 User 信息）时，自动且强制重定向至 `/pages/login/index`。
  2. 注册表单必须包含：昵称（长度1-32字，不可为空）、月薪（0-10000000元，必填）、月工作天数（数字，默认22天）、日工作小时数（数字，默认8小时）。
  3. 注册成功后，调用 `user-center.register`（若失败则本地 Mock 插入），创建完整的 `User` 对象并保存，然后跳转至首页 `/pages/index/index`。

### Requirement 2: 控制台首页概览与功能导航
- **User Story**: 作为一个已注册的用户，我希望一打开应用就能看到我今日已赚金额、当前职级，并能快速启动计时或查看各项趣味模块。
- **Acceptance Criteria**:
  1. 首页顶部必须显示：用户昵称、职级头衔（如“如厕专员”）、当前等级，以及距离下一级所需 XP 的水平进度条。
  2. 首页核心板块显式展示：今日摸鱼已赚 (¥)（实时根据今日已保存的 session 汇总）、今日如厕次数、累计时长。
  3. 中央具有一个极度显眼、带呼吸缩放动画的“开始拉屎”按钮。点击后跳转到计时页面。
  4. 提供前往“今日屎运”、“周报”、“我的职级”、“徽章成就”和“战队社交”的入口。

### Requirement 3: 带薪如厕计时器与久蹲提醒
- **User Story**: 作为一个正在拉屎的用户，我希望有一个炫酷的计时器展示我当前蹲坑的时长和实时累加的带薪工资，并提醒我不要蹲得太久。
- **Acceptance Criteria**:
  1. 计时页面应使用沉浸式暗色调（避免厕所里手机屏幕刺眼）。
  2. 开启计时后，时间（`MM:SS` 格式）必须每秒递增。
  3. 实时带薪收益根据当前用户的月薪计算：`秒薪 = 月薪 / 工作天数 / 工作小时 / 3600`。收益金额数字必须每秒累加更新（精确到两位小数）。
  4. 计时达到设置的久蹲阈值（默认 20 分钟）时，必须弹出温和的通知提示（“蹲太久了，小心痔疮哦”），并且手机产生振动反馈（调用 `uni.vibrateLong`）。
  5. 具备“我拉完了”结算按钮（跳转到结算页）和“中途放弃”按钮（终止计时返回首页，不记录本次数据）。

### Requirement 4: 结算、评价与升职动画
- **User Story**: 作为一个刚刚拉完屎的用户，我希望看到本次赚了多少钱、获得多少经验值，并能打分和添加备注。
- **Acceptance Criteria**:
  1. 结算时显示：如厕时长、本次带薪收入、获得的经验值 XP（基础10 XP + 每分钟+1 XP + 舒适度×2 XP + 连续打卡+5 XP）。
  2. 商品换算：显示本次收入可以购买什么（例如“相当于赚回了 0.5 杯瑞幸咖啡”）。
  3. 互动评价：
     - 提供 1 - 5 星的舒适度选择器。
     - 提供可选的随笔记录文本输入框。
  4. 升职处理：如果本次拉屎结算导致经验值达到下一职级阀值，在保存成功后，必须弹出一个遮罩浮窗，播放金色“升职加薪”的庆祝动画，展示新头衔（如“排泄主管”）。
  5. 点击“保存”按钮后调用 `session-manager.create` 保存记录，并返回首页。

### Requirement 5: 数据统计看板
- **User Story**: 作为一个关心理财和肠胃健康的用户，我希望以直观的图表了解我拉屎的时间规律、舒适度变化及月度分布。
- **Acceptance Criteria**:
  1. 统计页展示生涯总次数、总时长和总收益。
  2. 24小时频次分布：显示一个 0-23 点的直方图（CSS 柱状图），反映一天中哪个时间段如厕最频繁。
  3. 舒适度趋势图：以折线图形式（纯 CSS/SVG 绘制）展示最近几次拉屎的平均舒适度变化。
  4. 月度日历热力图：显示当月日历网格，根据每天拉屎次数填充不同深浅的暖橙色（类似于 GitHub Contribution Grid），点击某一天可显示当天数据。

### Requirement 6: 徽章成就系统
- **User Story**: 作为一个具有收集爱好的打工人，我希望通过拉屎来收集各种成就徽章，以增加乐趣。
- **Acceptance Criteria**:
  1. 徽章页网格展示 20+ 个徽章（来源于 `utils/badge-definitions.ts`）。
  2. 分类展示：已解锁徽章（全彩色，点击显示解锁时间及介绍）、未解锁徽章（灰度，点击提示具体的解锁要求）。

### Requirement 7: 战队社交与排行榜
- **User Story**: 作为一个乐于在办公室摸鱼的员工，我希望和同事组队，看谁是带薪拉屎之王，并看看大家的拉屎实况。
- **Acceptance Criteria**:
  1. 未加入战队时，提供“创建战队”和“加入战队”（输入6位大写邀请码）交互。
  2. 已加入战队时：
     - **排行榜**：按本周或本月带薪收益/时长/次数进行降序排行，并显示当前用户的名次。第一名有奖杯或“拉屎王”标识。
     - **动态墙**：实时展示组内其他成员的拉屎动态（例如：“神秘同事 刚刚带薪拉屎 12 分钟，赚取了 ¥8.50”）。

### Requirement 8: 周报与运势
- **User Story**: 作为一个充满幽默感的打工人，我希望看到自己每周的“摸鱼总结”，或者每天看一眼“屎运测试”来决定摸鱼时间。
- **Acceptance Criteria**:
  1. 周报页支持切换浏览历史周报。展示本周拉屎总次数、赚取总收益、实体商品换算列表、以及根据本周数据给出的搞笑吐槽战意评语。
  2. 运势页展示今日屎运评分，黄金带薪拉屎时段推荐，以及幽默的“宜/忌”建议。

## Non-Functional Requirements

### Code Architecture
- 页面必须保持逻辑单一性，大量与接口和本地存储交互的逻辑应下沉到 store 和 api 客户端中。
- 所有数据渲染前应带有默认空状态，防止接口延迟导致 UI 崩溃或闪烁。

### Aesthetics & Performance
- 完全遵循暖橙色（`$color-primary: #FF8C42`）为主的温馨调色板。
- 卡片采用圆角（`16rpx`）与柔和阴影，有按钮点击态反馈（如缩放或半透明）。
- 使用 **uCharts** 图表库绘制折线图和柱状图，日历热力图可使用纯 Vue 数据绑定的 CSS Grid 实现。同时集成 **Lottie** 用于播放升级、结算、夸奖和鼓励动画。
