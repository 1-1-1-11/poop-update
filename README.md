# 粑粑升职记 💩

> 每一次如厕，都是一次升职加薪的机会

当代打工人每天至少有 10 分钟在厕所度过——这 10 分钟不是摸鱼，是你的 **带薪资产**。

输入你的真实月薪，每次上厕所按下开始计时，「粑粑升职记」就按秒帮你算工资。拉完还能看到：这一趟赚了多少、够买一杯奶茶还是能加个鸡腿、职级升了没有。

把带薪拉屎变成一份正经事业。

---

## 有什么好玩的

### 计时赚钱
点一下「开始拉屎」，屏幕上的钱就开始涨。拉越久赚越多，每一秒都不白费。

### 看看这次值多少
拉完给舒适度打个分，系统自动算出：本次收入 + 经验值 + 够买什么。
_"这一趟赚了 3 块 5，够买一瓶可乐了"_

### 一路升职
从「厕所实习生」到「厕神 CEO」，一共 7 个职级，靠次数和经验往上爬。

### 收集成就
25 个成就徽章等着解锁，有普通的也有传说中的。金光一闪的那一刻很有成就感。

### 战队 PK
叫上朋友组个战队，每周排行榜 PK，看谁才是带薪拉屎王。

### 每天一签
每日运势告诉你今天哪个坑位最旺、适合拉稀还是憋着——仿黄历风格，图个乐。

### 看数据
拉了多少次、花了多少时间、赚了多少钱、什么时候最频繁——全部图表化呈现。

### 每周总结
每周自动生成一份拉屎周报，看看这周的 "业绩"。

### 两种皮肤
喜欢暗黑风还是清爽风？一键切换，整个界面和文案都会跟着变。**金融交易所**（暗黑看盘）或 **科学实验室**（学术报告），看你心情。

---

## 成果

一个完整的微信小程序 / H5 应用，包含 **12 个页面**，覆盖从计时、结算、统计到社交的完整体验。

可以在浏览器直接打开运行，无需下载 App，无需注册手机号，填个昵称和月薪就能开始玩。

---

## 怎么用

**体验地址**：本机运行 `npm run dev:h5`，浏览器打开 `http://localhost:5173`

或者在微信开发者工具中导入项目，体验小程序版本。

第一次打开会进入登录页，填一个昵称和你的月薪，就可以开始计时了。所有数据都存在本地，直接玩就行。
